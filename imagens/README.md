# Imagens e Prints do Projeto

Esta pasta armazena as imagens, fotos e prints relacionados ao protótipo do Sistema de Iluminação Pública Inteligente baseado em IoT.

As imagens servem como evidências visuais do desenvolvimento e funcionamento do protótipo. Elas demonstram a montagem dos componentes, os estados do sistema, o funcionamento do Monitor Serial, o código na Arduino IDE, o dashboard do Node-RED e o fluxo de integração utilizado nos testes.

## Objetivo das Imagens

As imagens desta pasta comprovam visualmente a montagem e o funcionamento do protótipo. Elas foram utilizadas como evidências no artigo acadêmico e na documentação técnica do projeto.

Os registros demonstram:

- a montagem física do circuito;
- os componentes utilizados;
- os estados de repouso e presença detectada;
- a execução do código na Arduino IDE;
- as mensagens exibidas no Monitor Serial;
- o fluxo do Node-RED;
- o dashboard utilizado para monitoramento;
- os testes individuais dos atuadores.

## Observação

Todos os arquivos desta pasta foram adicionados como evidências do projeto acadêmico Sistema de Iluminação Pública Inteligente baseado em IoT.
