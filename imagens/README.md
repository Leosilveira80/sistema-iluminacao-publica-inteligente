# Imagens e Prints do Projeto

Esta pasta será utilizada para armazenar as imagens, fotos e prints relacionados ao protótipo do Sistema de Iluminação Pública Inteligente baseado em IoT.

## Imagens previstas

| Arquivo | Descrição |
|---|---|
| montagem-circuito.jpg | Foto da montagem física com Arduino, sensor PIR, LEDs e buzzer |
| estado-repouso.jpg | Foto do sistema em repouso com LED verde ligado |
| presenca-detectada.jpg | Foto do sistema com presença detectada, LED vermelho ligado e buzzer acionado |
| print-arduino-ide.jpg | Print do código aberto na Arduino IDE |
| print-monitor-serial.jpg | Print do Monitor Serial exibindo os estados do sistema |
| github-repositorio.jpg | Print do repositório organizado no GitHub |

## Objetivo das imagens

As imagens servirão como evidências visuais do desenvolvimento e funcionamento do protótipo, demonstrando a montagem dos componentes, os estados do sistema e a organização da documentação no GitHub.

## Observação

As imagens serão adicionadas posteriormente conforme os novos prints e fotos forem produzidos durante os testes e a documentação final do projeto.
