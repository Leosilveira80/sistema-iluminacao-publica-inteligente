# Imagens e Prints do Projeto

Esta pasta armazena as imagens, fotos e prints relacionados ao protótipo do Sistema de Iluminação Pública Inteligente baseado em IoT.

## Imagens do Protótipo Físico

| Arquivo | Descrição |
|---|---|
| `montagem-circuito.png` | Foto geral da montagem física com Arduino, protoboard, sensor PIR, LEDs, buzzer e jumpers |
| `estado-repouso.png` | Foto do sistema em estado de repouso com o LED verde ligado |
| `presenca-detectada.png` | Foto do sistema com presença detectada, LED vermelho ligado e buzzer acionado |
| `arduino-uno-r3-closeup.png` | Foto aproximada da placa Arduino UNO R3 utilizada no projeto |
| `sensor-pir-closeup.png` | Foto aproximada do sensor PIR HC-SR501 |
| `buzzer-ativo-5v.png` | Foto aproximada do buzzer ativo 5V utilizado como atuador sonoro |

## Prints do Desenvolvimento

| Arquivo | Descrição |
|---|---|
| `github-repositorio.png` | Print do repositório organizado no GitHub |
| `print-arduino-ide-01.png` | Print da primeira parte do código na Arduino IDE |
| `print-arduino-ide-02.png` | Print da segunda parte do código na Arduino IDE |
| `print-monitor-serial-01-inicializacao.png` | Print do Monitor Serial mostrando a inicialização e estabilização do sensor PIR |
| `print-monitor-serial-02-repouso.png` | Print do Monitor Serial mostrando o estado de repouso |
| `print-monitor-serial-03-presenca-detectada.png` | Print do Monitor Serial mostrando a presença detectada |

## Objetivo das Imagens

As imagens servem como evidências visuais do desenvolvimento e funcionamento do protótipo. Elas demonstram a montagem dos componentes, os estados do sistema, o funcionamento do Monitor Serial, o código na Arduino IDE e a organização da documentação no GitHub.

## Relação com os Testes

As imagens comprovam os seguintes estados do sistema:

| Estado | Evidência |
|---|---|
| Montagem física | `montagem-circuito.png` |
| Repouso | `estado-repouso.png` |
| Presença detectada | `presenca-detectada.png` |
| Inicialização do sistema | `print-monitor-serial-01-inicializacao.png` |
| Estado de repouso no Monitor Serial | `print-monitor-serial-02-repouso.png` |
| Presença detectada no Monitor Serial | `print-monitor-serial-03-presenca-detectada.png` |

## Observação

Todos os arquivos desta pasta foram adicionados como evidências do projeto acadêmico e serão utilizados na documentação final do Sistema de Iluminação Pública Inteligente baseado em IoT.
